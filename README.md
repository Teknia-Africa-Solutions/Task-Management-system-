# TaskFlow - Task Management System

A comprehensive task management platform for student development teams.

## 🚀 Features
- Dashboard with real-time statistics
- Task management with filtering
- Project tracking with progress bars
- Team collaboration tools
- Calendar view
- File management
- Reports and analytics

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **Database**: MySQL
