# Frontend Preview Checklist

Use this checklist before pushing code or requesting review on any assigned branch.

## General review
- [ ] The page works on desktop
- [ ] The page works on mobile and tablet widths
- [ ] There is no horizontal overflow
- [ ] No text overlaps or gets cut off
- [ ] Buttons remain visible and clickable
- [ ] Inputs and modals are aligned properly
- [ ] Navigation is easy to use
- [ ] Sidebars and headers do not break the layout
- [ ] Cards remain readable and well spaced
- [ ] The page still looks clean and professional

## Josephine — Dashboard responsiveness
- [ ] Dashboard cards stack properly on small screens
- [ ] Chart containers resize correctly
- [ ] Spacing between sections is balanced
- [ ] No dashboard card text is cut off
- [ ] The overview remains readable on mobile

## Nayidah — Mobile navigation and layout
- [ ] Sidebar collapses or hides correctly on smaller screens
- [ ] Header does not overflow
- [ ] Search and filter buttons remain usable
- [ ] Mobile menu opens and closes correctly
- [ ] Layout remains balanced on narrow screens

## Okelo — Task list and creation flow
- [ ] Task list is readable and aligned
- [ ] New task modal fits on small screens
- [ ] Filter buttons are easy to use
- [ ] Status badges do not overflow
- [ ] Long task names wrap or truncate properly
- [ ] No task card breaks the layout

## Final approval checklist
- [ ] The branch is complete
- [ ] The issue is fixed
- [ ] Mobile responsiveness is checked
- [ ] No UI breakage is visible
- [ ] The feature is ready for review
- [ ] Pull request is ready to be opened

## Important note

Before merging to `develop`, confirm the design is still usable on smaller screens and that no part of the frontend breaks or overflows.
